QMT 执行层状态

只读查看；实时委托与持仓请在 QMT 客户端查看。

实时链路组成

  1. run_time 定时器（3 秒）触发 on_timer
  2. get_full_tick 取全市场 L1 快照，一级指标粗筛全部标的
  3. 候选池再算 K 线指标；持仓单独算盈亏 / 回撤 / 持有分钟
  4. 规则命中 → 风控硬前置 → 幂等 client_order_id
  5. passorder → 回报轮询 → 超时撤单 → 对账熔断 → 内存审计

买入扫全市场，卖出只扫已持有且可卖的仓位。

人工导入步骤

  1. 在「策略配置台」改好指标与阈值，保存到本地规则。
  2. 左侧导航点「导出沙箱规则」，生成 execution/qmt/rules_snapshot.py 并同步策略内核副本。
  3. 核对 shared/strategy_core.py 与沙箱副本哈希一致、规则指纹一致。
  4. 在标准版 QMT 内置 Python 沙箱里人工导入，先在模拟盘跑 broker_api.probe(C)。
  5. 逐条对照「实盘上线检查表」，收到券商对程序化交易报告的确认反馈后才考虑开闸。
硬约束：禁止用本工作台实时驱动 QMT；不做实时桥接；不把账号 / 密码写进项目。
